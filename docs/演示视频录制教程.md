# 演示视频录制教程

> 目标：2~3 分钟视频，展示「Ubuntu 虚拟机跑服务端 + Windows 客户端局域网调用」的完整过程。
> 录制前请先按 README 完成部署，并用 `python demo.py --host <虚拟机IP>` 彩排一遍，确认零报错。

## 一、准备清单

| 项目 | 说明 |
|---|---|
| 虚拟机 | Ubuntu 已按 README 启动服务（`bash run.sh`），终端窗口保持打开 |
| Windows 终端 1 | 打开 PowerShell，先 `ping <虚拟机IP>` 确认网络互通 |
| Windows 终端 2 | 进入 `client/`，用于运行命令行客户端 |
| 录屏工具 | Windows 自带 Win+G（Xbox Game Bar）或 OBS Studio |
| 分辨率 | 1920×1080，横屏 |

## 二、分镜脚本（共 8 个镜头，约 2 分 30 秒）

| 镜头 | 时长 | 画面内容 | 操作 |
|---|---|---|---|
| 1 项目结构 | 15s | Windows 资源管理器展示 `robot/` 目录 | 展开 server、client 文件夹 |
| 2 启动服务端 | 20s | Ubuntu 终端运行 `bash run.sh` | 截图 run.sh 输出：安装、IP、`Uvicorn running` |
| 3 网络互通 | 10s | Windows PowerShell | `ping 192.168.x.x`，显示"时间<1ms" |
| 4 查询接口 | 20s | PowerShell 运行 `python demo.py --host <IP>` | 展示 /status、/sensor 的 JSON 响应 |
| 5 运动控制 | 20s | demo 继续 | /move 后位置从 (0.00,0.00) 变为 (0.30,0.00) |
| 6 预设任务 | 35s | demo 轮询输出 | square 正方形轨迹逐步演化、自动回 idle |
| 7 停止中断 | 20s | demo 继续 | patrol 运行中被 /stop 中断；422/409 错误处理 |
| 8 图形客户端 | 25s | 运行 `python gui_client.py --host <IP>` | 点"执行预设任务 square"，右侧画布实时画出正方形轨迹；点停止 |

> 镜头 4~7 不需要任何剪辑，`demo.py` 一次运行自动走完，注意在镜头 5、6 处把输出滚动速度调慢或暂停解说即可。

## 三、录制步骤

### Windows 自带录屏（推荐，零安装）

1. 按 `Win + G` 打开 Xbox Game Bar，点"捕获"；
2. 点录制按钮（或 `Win + Alt + R`）开始；
3. 按分镜依次操作，`Win + Alt + R` 停止；
4. 视频保存在 `此电脑 → 视频 → 捕获`，格式 MP4。

### OBS Studio（可选，画面更可控）

1. 下载安装 OBS（https://obsproject.com ）；
2. 添加来源 → 显示器采集；
3. 设置 → 输出 → 录制格式 MP4；
4. 开始录制 → 按分镜操作 → 停止录制。

## 四、录制注意事项

1. **先彩排**：完整跑一遍 demo.py，确认时间点和输出符合分镜预期；
2. **终端字号调大**（Ctrl + 鼠标滚轮），保证 JSON 输出清晰可读；
3. **关闭无关程序通知**，避免弹窗入镜；
4. **虚拟机 IP 用真实值**，不要用 127.0.0.1（考核要求"通过局域网访问"）；
5. 录制时**边操作边按讲解稿念**，或后期配音（推荐前者，一次成型）；
6. 时长控制在 3 分钟内，超出部分可快进或裁剪。

## 五、交付检查

- [ ] 视频能清晰看到 Ubuntu 终端里的 uvicorn 启动信息
- [ ] 视频能清晰看到 Windows 端调用 5 个接口的请求与响应
- [ ] 正方形轨迹演化过程可见（非瞬间跳变）
- [ ] 有 stop 中断任务的画面
- [ ] 时长 2~3 分钟，MP4 格式，分辨率 ≥1280×720
